# E-Commerce Website

A responsive e-commerce website built using HTML, CSS, and JavaScript. The application fetches product data from the Fake Store API and dynamically displays products with a clean, user-friendly interface across desktop, tablet, and mobile devices.

## Features

- Fully responsive design
- Dynamic product listing
- Product data fetched from the Fake Store API
- Product images, titles, prices, and descriptions
- Responsive navigation menu
- Modern and clean UI
- API integration using JavaScript Fetch API

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fake Store API

## API Used

- https://fakestoreapi.com/

## Responsive Design

The website is fully responsive and adapts seamlessly to desktop, tablet, and mobile devices using CSS media queries. JavaScript is used to fetch and render product data dynamically from the API.

## How to Run

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. Ensure you have an active internet connection to fetch product data from the Fake Store API.

## Purpose

This project was developed to practice API integration, responsive web design, and front-end development using HTML, CSS, and JavaScript. It demonstrates how to fetch and display dynamic data from a REST API while creating a responsive user interface.
